THE GAME LOOP

Pass the Orb. Keep your answers unique.

Every round starts with a shared category and a hidden countdown. The player holding the Atlas Orb submits a valid answer that has not already been used in that category. A successful answer passes the Orb to the next active explorer without restarting the fuse. When the countdown expires, the Orb overloads and the round moves forward.

Think quickly

Read the shared geography category and find a valid answer that nobody has used in the current round.

Pass the Orb

Submit an accepted answer to pass the Atlas Orb. The same countdown continues, so the pressure builds for everyone.

GLOBE RUSH FAQ

Quick answers before the countdown starts

Is Globe Rush a multiplayer geography game?

Yes. Globe Rush uses live rooms and a shared game state so players compete in the same round at the same time.

Can I play with friends?

Yes. Private rooms support 2–10 players. Share the room code or invitation link with the people you want to play with.

Do I need an account?

You can play HUMANITY as a guest. An account is required for ranked play and for completed runs to appear in official account rankings.

Can a player repeat an answer?

An answer can only be used once in the current category. The game checks submitted answers against the approved answer set.

Is Globe Rush free?

Yes. Globe Rush is available free in your browser. No separate game download is required.
