HUMANITY FAQ

Frequently asked questions

What is HUMANITY?

HUMANITY is a browser-based geography game platform with two main experiences: Atlas Daily, a shared daily challenge, and Globe Rush, a live multiplayer answer race.

Do I have to install anything?

No separate game installation is required. Open HUMANITY in a modern web browser and start playing.

Can I play without signing in?

Yes. Guest play is available. Creating an account unlocks account-based progress and is required for ranked Globe Rush play.

Does HUMANITY work on mobile?

The website is designed to adapt to smaller screens. A desktop or laptop gives you more room for the live multiplayer interface.

How can I report a bug or send feedback?

Use the Contact / report a bug link in the footer of the main HUMANITY website. Include the page or game mode and a brief description of what happened.
